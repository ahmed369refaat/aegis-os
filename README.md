**نواة نموذجية (`no_std`, بدون أي اعتماديات) لبنية نظام تشغيل حديث: أسس Unix + عزل صارم افتراضي + طبقة مراقبة سلوكية أمنية باستجابة متدرجة.**

> الاسم: **Aegis** (الدرع) — النظام مصمم حول مبدأ واحد: كل شيء داخل نطاق (`Domain`) معزول، وكل صلاحية تُمنح مرة واحدة ثم لا تتغير إلا بالانخفاض.

## الفلسفة المعمارية في سطر واحد

> Unix أعطتنا الوضوح وتقسيم المهام وواجهات متماسكة؛ AegisOS تضيف فوقها قاعدة واحدة لا تُخترق: **الصلاحيات تتضاءل فقط (Attenuation-only)** — لا يوجد أي مسار كود في النظام قادر على توسيع صلاحيات نطاق حيّ.

## البنية

```text
┌──────────────────────────────────────────────────────────────────┐
│ نطاقات المستخدم: تطبيقات | خدمات | parsers | plugins | درايفرات │
└──────────────────────────────┬───────────────────────────────────┘
                        syscalls (بوابة قناع O(1))
┌──────────────────────────────▼───────────────────────────────────┐
│ طبقة النطاق Domain:                                            │
│   • قناع Syscalls (تضييق فقط)   • جدول Capabilities (أجيال)    │
│   • مساحة عناوين خاصة (W^X، Guard Gaps، Quota، Scrub)          │
└──────────────┬─────────────────────────────────┬────────────────┘
      المسار السريع الحتمي              المسار البطيء المجمع
┌──────────────▼──────────────┐   ┌──────────────▼─────────────────┐
│ Dispatcher: فحص بت واحد +   │   │ BehaviorMonitor: درجة خطورة    │
│ عدادات saturating + دفع     │   │ حسابية صحيحة + Hysteresis +    │
│ أحداث لـ Ring Buffer بلا    │   │ استجابة متدرجة Log→Tighten→    │
│ حظر/تخصيص                  │   │ Quarantine                     │
└─────────────────────────────┘   └────────────────────────────────┘
┌──────────────────────────────────────────────────────────────────┐
│ الاستجابة: كل قرار يُسجّل SecurityEvent في حلقة Telemetry        │
└──────────────────────────────────────────────────────────────────┘
```

الشجرة الكاملة وتفاصيل كل قرار تصميمي: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — خطة البناء المتدرجة: [`docs/ROADMAP.md`](docs/ROADMAP.md).

## الوحدات

| الوحدة | المسؤولية | أهم الثوابت المفروضة |
|---|---|---|
| `syscall` | ترقيم syscalls وقناع `u64` | `attenuate` تقاطع فقط؛ `try_narrow_to` يرفض أي توسيع |
| `capability` | جدول صلاحيات بمقابض غير قابلة للتزوير | `GRANT` مطلوبة للاشتقاق؛ الحقوق subset فقط؛ أجيال تمنع use-after-revoke |
| `memory` | مساحة عناوين لكل نطاق | W^X، محاذاة صفحات، منع NULL وwraparound، Guard Gaps، Quota، Scrub-on-release |
| `ringbuf` | حلقة SPSC للقياسات | سعة قوى العدد 2، فهرسة بقناع بتات، push لا يحظر أبداً (يُسقِط ويَعُدّ) |
| `profile` | قوالب النطاقات (service/parser/driver/plugin) | أقل صلاحية افتراضياً؛ EXIT محفوظة دائماً؛ لا NET مباشرة لأي قالب |
| `domain` | كيان العزل + المسار السريع | الحجر يمرّر EXIT فقط؛ العدادات saturating؛ الإحصاءات تتجمد أثناء الحجر |
| `monitor` | درجة الخطورة والاستجابة المتدرجة | رياضيات صحيحة u128؛ عتبات تتأثر بالحساسية؛ Hysteresis ضد الاهتزاز |
| `response` | تطبيق القرار + Telemetry | Tighten سطح إنقاصي ثابت؛ الحجر نهائي (الاستعادة = إعادة إطلاق) |

## تشغيل الاختبارات

```bash
cargo test            # 93 اختباراً: 87 وحدة + 6 تكاملية
cargo build --target thumbv7em-none-eabihf   # إثبات no_std حقيقي على ARM bare-metal
```

صفر اعتماديات خارجية (قسم `[dependencies]` فارغ عمداً — سطح سلسلة التوريد = هذا المستودع)، `#![forbid(unsafe_code)]` في كل الكود.

### عيّنة من الاختبارات الحدية (Edge Cases)

- تجاوز السعة العليا: `base = usize::MAX - PAGE + 1` → `Overflow` (لا wraparound)
- عدادات عند `u64::MAX` ثم إضافة → `saturating_add` (لا panic في أي مسار)
- المقبض الملوّث: revoke + إعادة استخدام الخانة → المقبض القديم يُرفض (فحص الأجيال)
- حدود العتبات: درجة 45 بالضبط تُحتسب tighten، و44 لا؛ 95+ حجر فوري من أول نافذة
- نافذة شرّيرة واحدة لا تحجر أبداً (Hysteresis) — ونوافذ متناوبة شر/سكون لا تتصاعد
- حلقة قياس ممتلئة: الإسقاط يُعدّ ولا يوقف المسار السريع ولا يعيد ترتيب الأحداث

## ماذا يمثل هذا المستودع؟

هذه نواة **نموذجية قابلة للتشغيل والاختبار** تُجسّد سياسات المعمارية كاملة (العزل، القدرات، الذاكرة، المراقبة، الاستجابة) في كود `no_std` مضغوط، مع تضمينها كأساس لمراحل خارطة الطريق (`docs/ROADMAP.md`): من الإقلاع والذاكرة الفعلية، عبر الجدولة وVFS، حتى نماذج التحليل الأثقل (ML) التي تستهلك مخرجات `BehaviorMonitor` نفسها.
